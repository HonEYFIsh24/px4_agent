## 当前行为

- 选点使用最新实际报告图；可靠旧图继续作为目标记忆，空图不会替代目标来源。
- 补充观察从同一目标的历史记录选择最后可靠观察，排除已否定、跨坐标纪元及关联歧义记录，复用既有confirming/recovery通道。
