## 本轮行为

- `landmark_association.py` 从同一有效地图的原始观测构造非权威关联假设；要求同标签、不同照片、不同视点、有限距离及单向投影相容/反向不相容。
- 同帧共现、不同类别、缺深度、无视点基线、无投影支持不归组；多候选关联保留 ambiguous，不沿链传递合并。已有歧义双向关联不能借较弱证据升级。
- `SemanticMap.snapshot()` 保存关联依据、涉及照片与两个 ID，并明确 `identity_confirmed=false`、`metric_evidence_merged=false`、`usable_for_confirmation=false`。地标记录数不等于实际物体数。
- 工作台对唯一的疑似重复对使用共享标签“疑似重复，位置待核实”。两个位置仍用空心点分别保留，橙色连接虚线表示冲突关联，不是飞行路径。详情保留两个 ID 和各自证据。
- 不改 `_associate()`、TargetMemory、目标确认、安全门禁或 NBV 评分。后续同帧共现可以撤销假设；地图失效后不生成假设。

新生成快照包含该字段；旧快照兼容读取但不会凭空补关联。原始历史记录不会被改写，离线派生回放放在单独目录。当前假设没有加入模型规划上下文，不能宣称已消除搜索决策中的重复实体。
