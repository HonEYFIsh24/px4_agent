原有桌面控制台新增“自主搜索工作台”页签，不启动网页，也不改变原有飞行、VIO、静态导航、安全控制或 Agent 选点逻辑。常规启动方法仍见 `docs/LOCAL_SETUP.md`。右侧可手动切换“实时左相机”和“观察照片”；前者复用原双目页的相机读取及新鲜度检查，遥测断连或图像过期时清空，后者使用已保存、已报告的历史截图，不把旧目标框叠加到实时视频。出现新复核图对时仍自动切换至多视角复核页一次。

工作台读取当前桌面进程已有的 command 审计记录与 `UAV_CAPTURE_EVIDENCE_DIR` 中原子保存的快照。地图必须属于当前指令，并与报告中的图片哈希、世界和架次匹配；候选还必须匹配地图修订、图片、世界、架次和坐标 epoch。原图读取时验证与视觉报告相同的 SHA256。没有快照、文件缺失、校验失败或旧版任务没有空间地图时显示等待/不可用；从未根据静态场景生成目标语义。实时飞机位置只有在遥测就绪且世界、架次与坐标 epoch 匹配地图时显示；遥测过期后隐藏实时位置与飞行状态。

地图为 ENU 平面：蓝色为几何观察，灰色为许可范围内尚未观察，橙色为已有语义吸引分数，绿色实线为工作台收到的实时 ENU 位置样本连接线；与原有 Gazebo 世界坐标航迹页分开。虚线圆是搜索区域，黄色虚线是当前预览候选的已预检规划路径，预测视野默认关闭、开启时只对当前未覆盖栅格着色。方向线段是无深度的视觉方位线索，不是目标位置；有定位的地标仍是视觉双目表面估计，不是独立验证的物体中心。图层复选框、滚轮缩放、左键拖拽、恢复全图、跟随无人机均只控制显示。

右侧列出当前地图对应的已预检候选，点击仅预览位置、路径、收益、代价和计算出的评分贡献；不会选点或调用执行器。模型选择的记录显示模型理由；确定性选择显示评分贡献。候选“预检”不等于执行器已接受，选中候选的执行阶段仅在当前任务和批次匹配实际 mission 时显示。观察列表点击可高亮实际观察位置与已记录视野，并显示该图片的报告、时间和检测框。框只对应保存的原始报告截图，模型自述置信度不显示为概率；缺双目标记无可靠深度。

“多视角复核”显示最近有双图的真实确认事件、原始图和复核状态；图像必须来自该任务的有效报告。单帧发现不显示为多视角确认。搜索状态与飞行状态分开；指标显示有效地图观察数、几何覆盖、已有完成记录的 NBV 任务数、模型调用数和墙钟时间。采样航迹不是连续真实轨迹，没有计算实际总航程；模型调用时间没有在此版本展示。缺少可验证数据时不填造数值。

当前边界：数据接口是桌面本机只读适配层，并不是新的网络 API；图片和地图依赖现有的 `UAV_CAPTURE_EVIDENCE_DIR`，不会自动加载另一次进程的历史任务。当前实时姿态接口未提供可靠的 ENU 航向，本版不绘制实时航向箭头；没有历史决策时间线、任意时刻 NBV 回放、点击地图点交互或独立实际航程统计。请用已授权的真实 Gazebo 闭环进一步验证运行期间的界面表现及性能。桌面页签不能修改 NBV 模式，也不会改变现有的单帧/多视角开关。

## 地图与输入体验更新

航迹监测页支持滚轮缩放、左键拖拽、放大/缩小及恢复全图；该图仍是 Gazebo 世界坐标下的实际位置采样。指令只有在后台确认接收后才清空；提交失败时保留原文，等待期间用户修改过的文字也不会被清除。多视角双图会适配面板大小，复核文字独立滚动且可调整区域高度。

语义工作台可显示经过世界文件 SHA256 核验的无标签静态碰撞包围盒俯视轮廓，使用地图的世界/ENU 注册变换；它不是物体的视觉实例分割，也不是所有高度均不可飞的禁区。观察点短线代表采图时机头方向。地标详情列出模型报告的物体名称、检测框与画面占比、观察次数、双目可见表面位置或未定位方位；橙色虚线椭圆为未标定的两倍标准差位置不确定范围，不是物体尺寸。若指令明确描述了地标与目标的附近关系，显示该指令关系；两个对象均有位置时用紫色虚线连接，线只说明任务描述，不证明关系被视觉验证。

现有 VLM 框和双目表面点不足以可靠推算物体的地面占据轮廓；界面明确显示“尚未测得”，不会将附近的静态障碍框冒充对应语义物体。当前关系抽取仍沿用搜索器原有的明确关系字符串规则，未涵盖复杂语序与全部空间关系。

## 2026-11-03 布局复验

在实际 13 号字体的桌面闭环截图中，首帧出现地图图层控件与画布挤压、观察摘要压住截图；先前独立组件的离屏尺寸没有覆盖到这个嵌套窗口。当前桌面将工作台置于可滚动区域，并优先按视口高度布局；候选说明、观察摘要及复核文字使用可滚动文本，图片保持等比缩放。空间不足时滚动工作台，而不是让控件互相覆盖。新增跨视角图对出现时自动切换至复核页一次，之后尊重用户手动切换；多地标和候选标签尝试避让，完整信息仍可在列表查看。相关小窗口几何与人工交互受控测试不等于更新后 Gazebo 实飞已完成。

显式启用 `UAV_WORKBENCH_ACCEPTANCE_DIR` 的验收记录器通过桌面输入框和正常提交方法执行；只有在驱动方完成预检并写入授权开始文件后才提交。新增随机种子进程取证、任务/场景归属及每帧页签可见状态；`workbench_visible` 仅证明 Qt 组件可见，**不保证窗口没有被系统其他窗口遮挡**。复核、候选和第二张观察的关键帧还要求界面实际显示对应内容，缺失时保留缺失，不靠离线渲染冒充现场截图。
