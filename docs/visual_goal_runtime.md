# 视觉关系目标

2026-11-11，按用户要求，将相对位置任务改为模型判断语义、程序负责通用执行。`staged` 的 approach、relative_hover、relative_land 共用此流程，没有增加任务种类。

模型根据用户原句和实际图像调用 `choose_task_goal`：当前位置满足要求选 `here`；移动选 `move` 并给出图中归一化地面点；不确定选 `observe`。程序用保存的相机标定、ENU姿态和已注册平地计算位置，经原路径规划、许可区域和一次性票据执行。到位后取得并报告新的真实图像，由模型通过 `review_task_goal` 比较参考图与新图，判断同一目标和用户要求的关系。满足就执行正常降落，未满足则继续选择或观察。

主流程不再强制证明车体前向、拟合前脸平面、达到固定两米距离、缩小角度误差或累加 confirmed 次数。度量诊断保留在 `task_runtime/object_frame.py`，不再作为默认工具或语义完成门槛；NBV恢复通用配置。主流程相关模块（orchestrator、single_vlm、autonomous_search、viewpoint_planner、reasoning、landing、execution，含新visual_goal）净减少约350行。

正常所属下降完成、实际落地上锁，以及到位新图的模型确认共同完成任务。触地后的速度重置或导航诊断缺失单独记录，不否定已完成的语义目标。飞行中的坐标有效性、碰撞、执行归属、落区支持面和下降通道仍由执行器检查。
