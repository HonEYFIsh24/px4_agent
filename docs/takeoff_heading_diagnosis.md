# 起飞航向重置诊断

本报告是对两次独立 Gazebo SITL 失败和一次后续只读地面检查的分析，不代表修复完成。后来在本机 ROS 日志目录找到了与两次实例的 PX4 启动日志路径一致的原始 ULog，两份均无 ULog dropout；下述高频信息来自对应 ULog，轮询记录仍单独注明。原始仿真、飞行与估计器记录保存在本机忽略目录；缺少原始记录时不能独立重放。PX4 源码版本为 v1.15.4 后的本地修改版本，不能推断其他版本行为相同。

## 实际配置

两次失败的启动参数应用记录及读回均一致：`EKF2_MAG_TYPE=0`（启动参数快照）、`EKF2_EV_CTRL=7`、`EKF2_EV_DELAY=0`、`EKF2_GPS_CTRL=0`、`EKF2_HGT_REF=3`、`EKF2_BARO_CTRL=1`、`EKF2_EVP_NOISE=0.20`、`EKF2_EVV_NOISE=0.30`、`EKF2_EVA_NOISE=0.26`。随后新的地面实例再次实际读取了这些值。`EV_CTRL=7` 根据本机 PX4 参数定义启用视觉水平、垂直位置和三维速度，不启用视觉航向。地面状态实际显示磁航向融合、视觉航向不融合；不能将 VIO 的任意初始航向当作地理航向。

### 路线 B：观察周期与两次失败的具体原因

两次失败的原始 `ekf.jsonl` 显示，本地位置源时间在重置前后分别从 41.296→41.808 s 和 44.324→44.828 s，间隔 **0.512 / 0.504 仿真秒**。`ExternalVisionFlightGuard` 只允许不超过 0.5 仿真秒的相邻源样本参与首次起飞对齐例外，因此这两次均未满足证据条件。首次失败时，计数变化时磁对齐标志还为 false，下一次轮询才显示 true，下一条本地位置源时间为 42.328 s，距离 41.808 s 又达到 0.520 s；这也是异步到达情形下不能简单扩展一次阈值就保证成功的原因。隔离插桩成功架次对应前后源样本间隔 0.472 s。以上是对应日志的可验证条件，并不排除其他架次因其他安全条件而拒绝。

原观察器以 0.5 墙钟秒为目标轮询间隔，与守卫的 0.5 仿真秒证据上限没有调度余量。观察器现改为 0.2 墙钟秒；守卫的 0.5 仿真秒上限、对齐状态、重置次数、单次许可、机架/VIO/水平和速度身份、异常降落及地图/票据保护均未放宽。仿真速度及负载可能导致墙钟与仿真时间比例变化，因此仍不保证源时间间隔必然小于上限；超限时仍应失败。

真实地面实例 `20261103-190805-gpC5hI` 在持续落地上锁的 19.995 墙钟秒中记录 100 条 EKF 观察，位置源时间差中位 0.200 s、最大 0.224 s、无超 0.5 s、无倒退或缺失，EV 融合始终就绪。独立最小起飞实例 `20261103-191133-WAnyEL` 采用同一场景和种子 17，任务 `35c874df929d` 的航向计数 1→2 时，守卫实际使用的本地位置源样本为 32.144→32.336 s，间隔 0.192 s；磁对齐 false→true 有真实源证据，记录 `takeoff_mag_heading_alignment` 后实际到达 3 m、正常落地并上锁。25～42 仿真秒内 85 条观察的最大源时间间隔为 0.224 s，无超限、倒退或融合未就绪。ULog `/home/fxxk/.ros/log/2026-11-03/11_11_38.ulg` SHA-256 为 `d96dddea4339a3ae1fb167182c63deb7403b8b5686477d9d13c7ffa0e319d14a`，无 dropout；其中位置源时间 32.248 s 计数 1→2，`delta_heading=-0.007043 rad`，姿态源时间 32.252 s 同步重置。两个实例均按身份关闭，确认落地上锁并读回恢复参数。

一次地面与一次最小起飞支持采样周期是这两次失败的一个具体因素，但不能证明高负载、不同仿真速率和其他失败下全部可靠，也不代表航向重置被消除。更重要的是，当前自主搜索为防复用旧坐标，已在地面 `begin()` 时绑定纪元；因此即使底层在无地图起飞中合法确认预期对齐，现有搜索会话仍会拒绝重置后的旧身份。要完成路线 B，仍需实现经过审计的独立起飞初始化阶段，并仅在对齐结束后首次创建搜索坐标身份；不能在空中沿用原来已绑定的搜索会话、地图或票据。

本机 PX4 `src/modules/ekf2/module.yaml` 和 `EKF/common.h` 的 `EKF2_MAG_TYPE` 只定义 0（自动）、1（磁航向）和 5（不使用磁罗盘），没有值 6；不能把其他版本的参数值直接用于本机。本轮没有调整航向融合参数。

### 本机源码中的触发链及证据边界

复核的源码版本为 `v1.15.4-1-ga7659ddf12-dirty`。`controlMagFusion()` 在刚从地面进入空中时先清除 `mag_aligned_in_flight`；`controlMag3DFusion()` 在磁融合正在运行且继续条件、航向对齐条件满足时，以下条件任一成立会调用 `resetMagStates()`：磁样本 reset、`checkHaglYawResetReq()`、WMM 更新。磁融合超时等分支也可调用该函数，不能仅根据计数变化排除所有其他路径。

其中，编译包含 `CONFIG_EKF2_TERRAIN` 时，`checkHaglYawResetReq()` 要求在空中、航向已对齐、尚未完成空中磁对齐，且滤波器估计的地形相对高度大于 1.5 m。注意这是滤波器的地形相对高度，表中 `local_z` 仅为相关线索，不能直接代替它。若当时 `mag_hdg` 或 `mag_3D` 有效，调用参数允许 `resetMagHeading()`，该函数依据磁场及磁偏角计算航向并调用 `resetQuatStateYaw()`；后者更新姿态、输出预测器及四元数重置计数。

`resetMagStates()` 在空中执行时**随后设置** `mag_aligned_in_flight=true`；自动模式依据该标志等条件在之后进入三轴融合。因此观察到空中磁对齐及三轴融合，符合磁状态重置后的结果，不能把对齐标志本身说成触发原因。位置和姿态输出比内部延迟滤波器时间晚，两个话题间的时间先后不等于同一调用栈的先后。

两份日志在位置重置时刻之前最近的可用磁融合样本分别为 41.794 / 44.648 s，均为 `fused=true`、`innovation_rejected=false`；三轴创新分别约为 `[-0.000126,-0.003577,-0.001455]` 和 `[0.001258,0.003349,-0.002613]`。41.808 / 44.668 s 的 `estimator_status` 磁检验比为 0.01847 / 0.01732，磁场强度为 0.48129 / 0.48521 G，故障位与创新拒绝位均为 0；磁场参考强度为 NaN，不能声称验证了参考场强。相近样本不是触发瞬间的完整内部状态，这些数据支持当时磁融合未明显拒绝，不证明传感器绝对准确。

相应最近视觉里程计样本为 41.792 / 44.632 s，`reset_counter=0`，其报告的姿态第三方差为 0.06862 / 0.06871 rad²，仅为输入报告值而非独立标定。最近事件标志样本分别停留在 6.792 / 7.788 s，不能用于断言触发瞬间没有其他内部事件；ULog 也没有记录该条件分支及当时 WMM 更新标记。因此 **HAGL 触发是与源码和时间线高度一致的假设，不是已证明唯一触发原因**。若需要区分各分支，应在隔离调试构建中只记录 `mag_sample.reset`、HAGL 请求、WMM 更新和融合超时及内部地形高度，不改变估计器行为；现有证据不支持修改正式估计器或安全门禁。

### 坐标参考和影子结果的限制

PX4 内部导航为 NED、机体为 FRD；MAVROS 的 `map` 位姿以 ENU 和机体 FLU 表达。VIO 输出为重力对齐但初始航向任意的局部世界坐标，适配器应用 IMU 到机身外参并生成 `vio_local` 到 `base_link` 的机身姿态；传输层通过 FLU/FRD 符号和四元数变换生成 MAVLink `LOCAL_FRD` / `BODY_FRD`，并非把视觉坐标声称为地理 NED。

以旋转矩阵 `R_A_B` 表示 B 向量转换到 A，完整姿态关系应为 `R_ENU_VIO = R_ENU_body · (R_VIO_body)^T`；二者须对应同一机身、同一时刻及已知外参。当前地面影子程序只比较两边水平 yaw 并用圆周均值统计，不能证明倾斜和动态状态下的完整三维配准。它限制样本时间差并拒绝失效与纪元变化，仍未建立时间误差、PX4 姿态协方差、VIO 相关误差及外参不确定性的完整传播；任意低的视觉方差也不证明高精度。

候选偏移以 PX4 当前磁航向为参考，因而与其相关，不能视为独立绝对航向反馈至同一 EKF。地面 45° 与默认朝向的历史对照说明跨架次偏移不同，但 45° 数据为离线 ULog 对照，并非第二次实时影子闭环。当前结果明确输出未验证协方差、参考非独立且不授权融合；不会输入正式飞控通道。

- **磁航向模式切换**：强相关但尚非内部调用级因果证明。本机 PX4 的 `checkHaglYawResetReq()` 对已离地、航向已对齐但未完成空中磁对齐的状态，在离地高度约 1.5 m 后请求重置；两次 ULog 位置样本分别约为离地 1.66 / 1.59 m。自动磁融合还会由地面磁航向切换至空中三轴融合。已有同源 ULog 高速字段支持该机制，但没有记录函数触发分支本身。
- **外部视觉航向参考冲突**：本次实际未融合视觉航向，故不能将该问题归因于同时融合两个航向；位置、速度及视觉高度实际融合。适配器使用任意航向的 gravity-aligned local FLU，变换到 LOCAL_FRD，并非已经地理校准的 NED。对三份同场景 ULog，在 30～47 秒窗口以源时间插值比较视觉姿态和 PX4 姿态的水平航向，视觉减 PX4 的中位差分别约 −1.587、−1.590、−1.588 rad（约 −91°）；这证实当前两者绝对航向参考不同，不能直接把现有视觉航向启用于 PX4。单场景相对跟踪精度不能验证跨航向、跨世界的绝对对齐或替代航向安全性。
- **不同初始航向的只读地面对照**：使用独立实例，仅将 Gazebo 机身初始航向改为 45°，其余飞行融合参数未作为实验因素改变；整个采样期间持续确认地面上锁，记录 8 个状态样本、约 14 个仿真秒，重置计数不变，结束后实际读回确认参数恢复。对应 ULog 无 dropout，仿真真值航向约 0.7854 rad，视觉航向约 0，PX4 航向约 0.7905 rad，视觉减 PX4 的中位差约 −0.7904 rad。与原初始朝向的约 −1.59 rad 不同，说明不能使用固定补偿覆盖不同初始姿态。使用真值的比较仅为离线评估，不可在任务在线读取真值；此次没有解锁或飞行，也未启用视觉航向融合。
- **地面参考偏移的离线探索，不是可部署标定**：对历史记录与上述地面对照，共 45 份候选 ULog，按现有消息和时间戳筛选后纳入 38 份、排除 7 份；在 10～15 秒的已记录未解锁且未离地时间窗，用 PX4 姿态与视觉姿态的中位差构造每架次偏移，再仅以 15 秒之后的仿真真值评估。38 份中 30 份的后续数据包含空中状态、9 份的真值航向变化超过 0.5 rad；各日志的绝对误差 95 分位最大约 0.0401 rad，最大单点误差约 0.0408 rad。该探索没有验证标定窗口每个样本的磁航向可靠性、连续稳定条件、时钟偏差、完整坐标协方差变换或线上故障切断；历史架次多数共享相近初始姿态及场景，排除及视觉质量筛选也引入选择偏差。它只表明地面参考对齐值得进一步受控验证，不能据此启用视觉航向、关闭磁罗盘或声称飞行安全。
- **地面初始化尚未稳定**：瞬时就绪不是足够证明；但两次失败前地面已持续稳定，且新增地面样本也无计数变化。因此简单延长地面等待不能消除由离地条件触发的重置。
- **误判或实例切换**：ULog 中 PX4 位置与姿态计数、`delta_heading` 和 `delta_q_reset` 均发生变化，两次使用同一主估计器、视觉 reset_counter 不变。可以排除“仅由 Python 轮询或解析构造了计数变化”，但不同主题及滤波延迟仍限制因果判断。

已有安全守卫在受限起飞阶段有一套历史磁对齐证据流程，但这两次相邻位置源样本间隔约 0.512 / 0.504 s，超过其 0.5 s 证据边界，因此拒绝并触发安全降落。**本轮没有扩大该边界、忽略计数变化或复用旧地图。** 调整证据窗口或使用已有例外来继续飞行均不能在当前用户约束下视作修复。

## 验证状态与下一步

**实时地面影子观测**：新增只读采集脚本 `scripts/observe_ground_heading_reference.py` 和策略 `vio/heading_reference_probe.py`。它只订阅 VIO 影子位姿和 MAVROS 位姿并读取现有状态，不发布航向、不调用飞行控制接口、不读取仿真真值；输出是研究候选而非飞行授权。采样要求落地上锁、VIO 与 EKF 健康、磁航向标志有效、世界/估计器/VIO/位置及速度重置身份一致；所选 PX4 位姿、磁与 EKF 源状态必须不晚于视觉帧。当前状态始终单独检查，缺失或失效会清除候选并停止。磁观测字段由 EKF 观察器透传实际标志，缺失为未知，不作健康假设。

独立地面实例的最终复测采得 97 对样本、跨约 11.8 仿真秒，全部记录为地面上锁；PX4 位姿落后视觉样本最多约 0.036 秒，所选 EKF 和磁状态源时间均不晚于视觉帧。样本偏移约 −0.0403 rad、窗口最大偏离约 0.00351 rad，视觉航向方差最大约 0.0688 rad²；这只是静止地面的一个实际窗口，不是飞行精度或标定验收。此前一次严格实时复测因 EKF 与视觉源时间在序列化后相差 1 ns 而拒绝，原始失败样本保留；最终改为选择真实更早的同身份 EKF 状态，并同时检查最新状态，没有增加时间容差。实例退出后确认原参数恢复。

影子观测尚缺 PX4 姿态协方差、动态运动及磁干扰下独立验证；稳定阈值仅供实验筛查，不得把 `candidate_only` 当作可启用视觉航向的依据。坐标和状态变化导致的模拟失效已通过受控测试，但未人为在实际飞控中注入故障。

对照一个较早完成搜索的架次，其 ULog 也记录了在约 1.66 m 高度的相同航向计数重置；原执行器记录显示该次进入已有的起飞磁对齐例外流程。另一个有完整换位但视觉采图失败的架次也在约 1.66 m 发生同类重置。因本轮明确禁止依靠忽略航向重置或复用旧坐标继续，该历史流程不构成符合当前要求的修复。PX4 的离地高度重置条件同时用于自动和磁航向融合路径，因此只将自动模式切换成始终磁航向并没有源码证据表明能够避免重置。

已新增只读脚本 `scripts/analyze_heading_ulog.py`：记录 ULog 哈希、参数、PX4 航向与姿态重置、此前可用的标志采样和视觉里程计时间戳，并可离线重放地面 PX4/视觉航向参考对齐。当前回放使用不晚于视觉源时间的 PX4 姿态（最大 0.05 秒），筛除磁航向未对齐、磁故障或场受扰，且拒绝所选地面窗口内的视觉及 PX4 姿态重置；这些只是离线筛查，不是线上安全证明。对齐只使用地面 PX4 及视觉数据，仿真真值仅在后续时间段评分；输出使用独立新文件且不控制飞机。项目虚拟环境所需的可选依赖列在 `requirements-diagnostics.txt`，例如用项目安装工具将它安装到 `.venv` 后运行：

```bash
.venv/bin/python scripts/analyze_heading_ulog.py "$INPUT_ULOG" --output "$NEW_OUTPUT_JSON"
```

重置和状态主题的时间基准、采样延迟及标志在事件附近的因果关系仍需谨慎解释；脚本不会判断类别真值或自动决定航向配置。

地面只读验证已完成并确认参数恢复。新增受控测试覆盖上述轮询边界时不静默接受重置；航向守卫、相机与搜索隔离相关回归通过。没有执行新的最小起飞、旋转后采图或完整搜索；它们均不能记为通过。

当前无经验证的配置修复：在本机源码中，切换为始终磁航向不一定消除离地后重置；关闭磁场或启用视觉航向需要先独立验证替代航向的绝对参考和可靠性，不能仅因单场景相对航向误差小就直接改。下一步应基于已有 ULog 研究能否采用不改变坐标安全门禁、可验证且可恢复的 PX4 SITL 配置或启动流程；任何单因素参数对照须独立架次、先快照后还原，并保持异常时自动降落。若证据不足，应维持当前失败和安全落地，而不是将等待或重配准当作成功。
